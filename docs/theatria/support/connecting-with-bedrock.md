# Connecting with Bedrock

The recommended way to play Theatria is with **Java Edition 26.1.2**.

Bedrock clients can technically connect, but Bedrock support is not recommended or guaranteed. Connecting requires extra account-linking steps, and Bedrock updates can temporarily make the connection incompatible until server-side support catches up.

## Address and Port

* **Address:** `mc.playtheatria.com`
* **Port:** `19132`

## Account Linking

Your Java and Bedrock accounts must be linked before connecting. Follow the [Geyser Global Linking guide](https://link.geysermc.org/start).

If these instructions stop working after a Bedrock update, use Java Edition or check the [Support page](./) for current assistance.
